# redesign-sirius.by

Независимый frontend-прототип редизайна главной sirius.by (Local Media). Направление 1 «Под краном».
Не связан с production-сайтом, ссылки ведут на реальные страницы sirius.by. Ветка `redesign-v2`; прежний wireframe — в ветке `baseline-before-design-skills`.

- `index.html` — главная; секции помечены `<!-- WP: ... -->` для переноса в блоки ACF/шаблоны WordPress.
- `assets/style.css`, `assets/main.js` — без зависимостей; motion уважает `prefers-reduced-motion`.
- `assets/img/` — фото продукции sirius.by, вырезанные из белого фона (×2), `yard.jpg` — фото площадки с краном (520×437).
- `assets/logos/` — логотипы поставщиков со страницы sirius.by/about/suppliers/.
- Форма заявки демонстрационная и ничего не отправляет.
- Факты о бизнесе — `PRODUCT.md`.
